# Futures list

## Commands

- [x] link - symlink a file or dir
- [x] copy - copy a file or dir
- [x] rm - remove a file or dir or unlink a symlink
- [x] run - run a shell command
- [x] log - log a message
- [x] env - set/get/drop env vars
- [x] input - get input from the user
- [x] var - declare a variable

## Flow control

- [x] if - holds a block of commands that will be executed insha'Allah only if the connation is true
- [ ] jump - jump to a specific location, this one takes a string that is the localtion name, and then it's executed to have to location node with the same value declated some where below or above.
- [ ] location - declare a location with a name.
- [ ] repeat - repeat a set of commands several times.
- [ ] stop - stop the execution of the script

## Threads

- [x] fork - fork a new thread in the thread stuck and continue the execution inside the new thread
