# Futures list

## Commands

- [ ] link - symlink a file or dir
- [ ] copy - copy a file or dir
- [ ] rm - remove a file or dir or unlink a symlink
- [ ] run - run a shell command
- [ ] log - log a message
- [ ] env - set/get/drop env vars
- [ ] input - get input from the user
- [ ] var - declare a variable

## Flow control

- [ ] if - holds a block of commands that will be executed insha'Allah only if the connation is true
- [ ] jump - jump to a specific location, this one takes a string that is the localtion name, and then it's executed to have to location node with the same value declated some where below or above.
- [ ] location - declare a location with a name.
- [ ] repeat - repeat a set of commands several times.
- [ ] stop - stop the execution of the script

## Threads

- [ ] fork - fork a new thread in the thread stuck and continue the execution inside the new thread
- [ ] join - join a thread, which means go a step back to the previous thread in the threads stuck.
