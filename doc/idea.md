# What is this?

this is insha'Allah a simple and minimal cli to manage your dotfiles.
the main idea is to make this process (dotfiles management) as easy and as fast and simple as possible.

# How, What's new?

- all ur dotfiles are talking the same humane readable language (kdl).
- make the common actions (like for e.g change the theme of evry thing) automated.
- git native.
- no need to version control the generated or installable files (like the themes).
- make the small hand setup steps automated (can run scripts on events insha'Allah, ci/cd inspired).
